# Vallabh Verification Relay

This public repository is only a CI verification relay for an exact private commit. Product source does not belong here.

## Safety contract

- A PASS always names one exact private commit SHA.
- Do not commit private product source, private diagnostics, credentials, tokens, or authenticated URLs here.
- Never paste secrets into commits, issues, pull requests, workflow inputs, or logs.
- The private repository remains the sole source of truth.
